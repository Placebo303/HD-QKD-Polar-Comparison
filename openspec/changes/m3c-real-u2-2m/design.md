# Design

Reuse `m0_realframe_runner.load_real_series("2M")`, `load_bundle("2M")`, and `superframes`; these assert the R1 alignment, pair count, and 60/20/20 split before decoding. Pin the returned eval count to 383 and frame order to M0's VAL+HOLD role. Load the accepted M3-a arm1 or arm2 JSON through M3-b's structural validator. Use the stored 200-row prefix for Stage-1 and all 208 rows for Stage-2. Both calls are cold and use M0's `decode_real` semantics: real `a&31`, `b&31`, same-source R1-TRAIN prior, b2f soft marginal, max_iter 300, streak 3. M3-c performs zero new PEG builds.

The only Stage-2 trigger is `Stage1 u2 exact_match == false` determined with Alice truth after Stage-1. Persist this as `oracle_assisted=true`. Count a converged wrong reconstruction as undetected at each stage, separately from success. If Stage-1 is exact, final u2 output is Stage-1; otherwise final is Stage-2. For each frame report Stage-1/Stage-2 exact, final exact, per-stage undetected, wall/iterations, and `full10_match` using M0's report-only u1 argmax. Full10 mismatch never changes the u2 success label. No tag is sent or verified; no f, beta, SKR, security leakage, accepted-frame yield, or deployable IR result is calculated. Optional 5m syndrome-bit counts must be labeled nominal, not a transcript.

The runner requires both real-execution flags and a fresh direct-child root under `workspace/m3c_real_u2_20260926/`, rejects protected/escaped roots before source reads, flushes per-frame rows, and stops on structural/input/budget faults without retry/resume. A POSIX per-call timer stops decoding at the smaller of 300 s and the remaining internal arm deadline of 5280 s. The 120 s reserve lets the runner retain a terminal row and append-only execution event before the external 5400 s watchdog. A decoder timeout is a terminal incomplete-run event with its row retained. Fake injected I/O and decoder tests cover gates, graph identity/prefix, exact Stage-2 set, one failed rescue, undetected isolation, u1 claim ceiling, output identity, and budget stop. No test may call the production real reader or decoder.
