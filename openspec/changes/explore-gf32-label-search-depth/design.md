# Design

Reuse accepted pure graph, GF32, objective, pairing and observation helpers.
Keep onepass/deep as two explicit arms, no generic scan framework or global
mutation. Deep repeats the existing coordinate rule up to8 total sweeps,
records each sweep and retains same gauge class. Complete and partial
summaries follow the frozen packet; all accounting is per attempted call.
Preserve existing runners/results. Independent review precedes dispatch and
batch evidence acceptance. User grant covers this batch once only.
