# Design

Reuse D10 construction and profile admission unchanged. Explicit max8 paired
attempts per graph-ID group, first commonly admitted pair at the same seed/j,
retained failures and all returned matrices, including unselected admissions.
No label/decoder execution. Minimal JSON evidence under packet C1–C4 and caps.

The pre-execution FROZEN v2 amendment in the packet supersedes independent
per-profile selection: six paired groups use a common construction seed and
select only the first j where both profiles admit. Both expected-failure arms
are attempted and retained at each j. Max96 calls/no performance selection.
