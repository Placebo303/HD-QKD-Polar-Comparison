# M2 accounting replay design

Input is an explicit list of three `rows.json` paths (1M, 1p5M, 2M); the module has no default input path and writes only stdout. Read `summary.source`, `summary.H_corr`, and its `arms`. Require each source exactly once and four new-method arms per source (HDC and LB, two m values); reject missing or duplicate arm identities. The data are trusted local research artifacts; errors may be simple `ValueError` exceptions.

For each arm, preserve source/family/m, `blocks_done`, `superframes_done`, `fer_blocks`, `sf_success`, `sf_total`, and original reported f labels. Let `D=superframes_done*1024*H_corr`, `E=lambda_parts.leak_EC`, and `T=lambda_parts.tag`. Report `f_ec_actual=E/D` and `f_with_recorded_tags=(E+T)/D`. Report `tag_bits_recorded=T`, `tags_per_superframe=T/(64*superframes_done)`, and `f_if_one_tag_per_superframe=(E+64*superframes_done)/D` as a **counterfactual only**. Do not overwrite `lambda_parts` or infer that the counterfactual is an executed verification scheme. Require `blocks_done=16*superframes_done` and `T=64*blocks_done` for these complete T3 roots; otherwise fail the replay rather than silently change units. Zero or incomplete denominators fail.

`f_eff_actual`, D2 branch, LB `backend_used`, and method-family rank are absent, not guessed. Print JSON with `status="DIAGNOSTIC_UNREVIEWED"`, formula/units, source-separated arm rows, original-root paths, and the claim ceiling. Results become citable only after the DECIDE replay packet and independent Pre-RESULT gate. This script changes no existing file on execution.
