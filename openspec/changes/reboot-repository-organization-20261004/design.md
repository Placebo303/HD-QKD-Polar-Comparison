# Design

Use Git moves for tracked material and native moves into `workspace/_quarantine_20261004/` for untracked clutter. Record exact old/new paths in `docs/archive/PATH_MAP.md`; historical references remain verbatim. No forwarding code is presumed necessary.

Archived tests are not part of default discovery. Smoke uses the repository `.venv`, pytest with cache disabled and a new additive workspace temp root. A collection smoke proves import/discovery only; it must not be presented as an executed test suite. A failed applicable smoke stops further moves until its scoped cause is resolved.

Compact ledgers retain current constraints and the complete schema contract, with archived line references. Evidence states remain unchanged by filing. Never infer completion, acceptance, authorization, or promotion from archive placement. Unclear disposition is a concrete review item, not permission to merge an old delta.
