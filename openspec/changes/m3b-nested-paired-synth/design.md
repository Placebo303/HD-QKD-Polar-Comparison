# Design

Reuse `p1_stage1_runner.execute` and `b2f.decode_block_marginal`; do not implement a new decoder. New M3-b constructor callbacks load one accepted `workspace/m3a_nested_200p8_20260926/arm{1,2}.json` and return its full 208-row triple list for both construction calls. Before decode, pin arm identity, base/extension seeds, n=1024, GF(32), 200/208 ranks, zero four-cycles, eight degree-10 additions, exact base prefix, and saved file location. Two callbacks load the **same persisted artifact**, so output provenance must say `stored_artifact_loaded_twice`; it must not say M3-b performed two new PEG constructions. M3-a's prior `twice_identical` assertion remains a separate upstream fact with its documented persistence limit. The P1 core forms rows[0,200) for cold Stage-1 and rows[0,208) for cold rescue. Compare against P1 old arm with matching construction seed label and the same 240 frame seeds; graph edges differ by design.

The existing P1 core has hard-coded `workspace/P1_STAGE1/` root routing and A208/P1 wording. The implementation must make a minimal additive extension or isolated adapter so that new roots live under `workspace/m3b_nested_paired_20260926/` and every persisted summary, markdown result and graph label says M3-b nested A200+8, not historical A208. Existing P1 function defaults and outputs must remain bit-for-bit behaviorally unchanged. A fake injected-constructor test must prove no production constructor or decoder is invoked by dry mode or tests, and an output-provenance test must reject A208 mislabeling. Do not monkeypatch P1 globals or rewrite historical artifacts.

The measured denominator is 240 frames per arm. Stage-2 is exactly the Stage-1 non-exact set; both stages are cold. `undetected` remains failure and separately counted. Report matched-frame outcome transitions and per-arm modeled `E[leak]`, `f_exp`, `f_eff` on the P1 entropy basis, but charge the extra 40 bits on **every attempted rescue**, even when it fails. A failed rescue has still disclosed its rows. The old P1 roots are read-only comparators; their persisted R1 efficiency is historical and not a corrected comparison number. Old P1 R1 can be diagnostically recomputed as `E=1078`, `f_exp=1.2644508670520231`, `f_eff=1.284391179552023` (one extra 40-bit disclosure over 240 frames), pending independent acceptance. Never pool the two graph instances or call modeled synthetic disclosure observed real-data leakage.
