## 0. 论文定位
- **核心论点**：到达时间编码的高维协调本质上不是高维问题。误差只发生在相邻 bin，协调成本与维度 d 无关，可以精确降为近似二元的问题。
- **多元的位置**：理论上二元拆分没有损失；但在窄 bin 或宽符合窗的工作点，误差支撑变成 {−k..k}，这时结构感知的非二元码有真实优势。论文要给出由物理决定的占优区间，而不是「多元更复杂所以更强」，也不是「二元一定更好」。
- **码长的地位**：码长 N 是每种方法内部优化的参数，不是比较的主轴。主比较是每种方法在各自最优 N 下的每段采集净密钥。
- **不声称**：新码；首次在真实数据上做协调（Zhong 2015、Liu 2019 已做过）；单点 `f ≤ 1.3` 认证。可以声称的是：在同一批真实到达时间数据上，同口径、多族的系统研究，加上结构的精确拆分。

## 1. 论文结构
1. 信道刻画（真实数据）：误差支撑；两级精确拆分；q 元对称假设带来的熵高估；物理模型 p(bw, σ, δ)。
2. 结构感知协调协议：两级 / 多级二元，以及 GF(2k+1)；只需 2 个（或少数）参数；推广到 k-bin 符合窗。
3. 真实数据上的系统对比：二元 / 非二元 × LDPC / Polar × 利用结构 / 不利用结构，同口径，干净 OOS。
4. 系统后果：SKR(d, bw) 曲面；最优工作点随协调方式的移动；最佳 N 与采集长度的关系；短采集部署；时延校准增益（若 C-0 成立）。

## 2. 主度量与口径（R16，新增）
- **主度量**：每段采集的净密钥（bit），以及每个符合事件的净 kept：
  `Σ_blocks [kept·(1−fail) − L_EC − tag] / 采集对数`，并计入尾部浪费（切不满一块的符号）。
- **同时报告**：完整符号、带期望良率的 f；FER；undetected（单独列）；吞吐率（同一台机器，单线程与并行）；内存。
- **β 只作附带列**，并附说明：d 很大时 H(A) 也大，β 会显得接近 1。正文结论以 f 和净密钥为准。
- **R16**：
  - 方法之间的主比较，一律在每种方法自己的最优 N 下进行，N 的候选为 {1024, 2048, …, 65536}，并且受采集长度约束；
  - 另附「相同译码时间下的 f」比较，用来量化复杂度的代价。

## 5. 补测数据计划（交用户）
- **目标**：每个主要工作点约 300 个真实块（N=16384），约 500 万对符合（推导）。这样真实 FER≈1% 时，上界约 2%。
- **工作点**：至少 3 组 (bw, 符合窗)，分别对应误差支撑 k=1、2、≥3；每组覆盖 2 个损耗设置。具体组合由 C-0 / C-2 结果确定后写入 C-5 的 Pre-EXECUTE。
- **角色**：每段采集按时间切分，前缀只用于参数估计（约 1 万对即可），其余作为测试。新采的数据在使用前一律视为干净 OOS。
- **采集时长**：按实测事件率换算；若单段 10 s 不够，就采多段短采集，并按段报告。

## 6. 统计与功效（R1）
- **真实数据**：成功计数配精确置信区间。同一 N、同一组块上的方法对比做配对检验（McNemar）。个位数的失败计数只能写作「未定」。
- **合成数据**：每点 B ≥ 300；最终工作点用 B ≥ 1000 收紧 FER 上界。
- **证据类型分列**：合成（已验证信道）/ 真实一致性 / 真实 OOS 测量，三类分开报告。
