## 2. 卡点与根因（按严重度）

- **P0 MSD真实传递**：先验估计问题，非结构问题（假设强度：诊断级证据+机理自洽，

- **P1 维度泛化不对称**：MSD框架维度通用；NB 5+5分层是d=1024特定的。
  维度扩展主力=MSD（被P0阻塞中）。每新维度1–2周。

  需半自动sweep（见§4）。

## 4. 推进顺序

- **Phase A（先决，1周）**：M1″-prior（平滑/下限）→ (1024,200)合成重验 → M5-repeat。
  成功标准：MSD真实一致（带内）且 f≤1.6（传递证明门，比运营门1.35宽松——A只证传递，
  格点运营另按1.35考核；分阶段标准已声明）；否则回炉，不开矩阵。
- **Phase B（试点，1周）**：自动化sweep脚手架 + 2个新格点（如(256,200),(1024,100)）
  全流程，验证成本模型与MDE。**证伪规则**：若试点实测成本超模型50%以上或任一格点
  出现模型外失败类，冻结矩阵、先修模型/脚手架（Phase C不开）。
- **Phase C（矩阵，2–3周）**：剩余26格点sweep；每4格点一批末审查；NB后备臂只在
  MSD不一致格点补跑（省成本）。80%规则处置：达标照常收口；未达标（<80%）则停矩阵、
  转针对性修复（失败类聚类后立项），不接受部分曲面发表。
- **Phase D（收口）**：G0=(B)增补包：效率曲面 f(d,bw)、方法对照、负结果登记。
