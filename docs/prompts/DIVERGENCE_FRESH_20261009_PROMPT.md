# 发散用 prompt — 全新对话，不读本仓库（2026-10-09）

> 用法（第 3 步，用户手动执行）：
> 1. 开一个**全新**对话：不在本仓库里开，不开项目记忆，不上传任何项目文件，
>    不提 LDPC、Polar、协调效率 f 这类词。
> 2. 把分隔线之间的内容原样粘贴。`[请填]` 两处由你填写（或删掉）。
> 3. 换视角再跑 2 次：把第一行「视角」分别换成附录里的 B、C（最好用不同模型）。
>    多个视角给出相同结论，**不等于**结论被验证。
> 4. 不要追问"哪个最好"。把每次的完整输出存下来，交给回收 prompt
>    `docs/prompts/DIVERGENCE_RETURN_20261009_PROMPT.md`。

视角：请从**量子网络架构研究者**的角度思考。不要默认支持下面这个平台现在的用途。

**平台事实**（均为实测，别的不要假设）：
- 光源：自发参量下转换（SPDC）产生时间-频率纠缠光子对，有 Type-0（无滤波）和 Type-II 两种源。
- 探测：两路单光子探测器加时间标记器，原始时间戳为 ps 级。
- 符合时间差 Δ 的分布：
  - 高斯核 σ≈17–20 ps（Type-II）/ 24–27 ps（Type-0）；
  - 另有约 1–2% 的宽成分（σ 约 100 ps 量级），来源未定；
  - 3 s 内中心漂移 < 1 ps；
  - 两路之间曾有约 50 ps 的残余时延偏移，来自旧对准流程的量化，可以校准掉。
- 计数：符合偶然比（CAR）约 500–1000（Type-II）/ 100–200（Type-0）；Type-II 约 1.7–3.3×10⁵ 对符合/秒，单路计数 1–2 MHz。
- 数据形态：只有 3 s 和 10 s 的短采集，小批量。
- 当前用途：到达时间编码的高维 QKD。时间轴被切成约 200 ns 的帧，帧内 bin 宽可选 50 ps–6.4 ns，维度 d = 帧长 / bin 宽，是后处理时自由选的。
- 能否做共轭基测量（例如 Franson 干涉）：[请填：能 / 不能 / 不确定]。
- 研究者的时间约束：[请填：例如距离毕业还有几个月]。可以少量新采集，以软件和分析为主。

**任务**：

1. 先独立提出**至少 6 个**科学问题，**不要排名**。要求：
   - 覆盖三类：性能问题、原理问题、架构问题；
   - 至少 1 个来自跨领域视角（经典光通信、时频计量、定时同步、网络信息论任选）；
   - 至少 1 个反直觉或高风险；
   - 至少 2 个要求**改变研究目标本身**，而不是把现有用途的某个指标做得更好；
   - 任意两个问题的核心机制不能相同。
2. 对每个问题分别给出：
   - 为什么重要；它依赖哪些假设；
   - 证据 / 推测 / 未知，三者分开写；
   - 最接近的 3–5 篇原始文献：只写作者、年份、题目大意，**一律标注「待核实」，不要编造 DOI**；
   - **一个能推翻它、成本最低的计算或实验**，说明在上面这些平台条件下能否做；
   - 如果核心假设失败，还剩多少独立的研究价值；
   - 时间尺度：≤ 6 个月，还是长期。
3. 单独列出：你认为上面的平台描述里，隐含了哪些**可能是错误的假设**，或者问错了问题的地方。
4. 不要评价能发什么期刊；不要给"最推荐"的排序；不要把所有问题都收回到 QKD 密钥率上。
