## 1. 宏观诊断：我们现在到底站在哪里

### 1.1 已跨过的坎（科学事实，带作用域）

在冻结会计口径（超帧 n=1024 GF(32) 符号、整帧含 64-bit tag、
`f_super=(5·(m1+m2)+64)/852.544 ≤ 1.3`、`content=852.544 b`）下：

| 结论 | 证据 | 作用域 |
|---|---|---|
| 可解码性不再是约束 | 软边际 L2（无 genie、无 L1 码、D-u1=0）：F208 `0/240`（构造实例 2026092001，girth 8）与 `0/240`（2026092011，girth 6） | 合成配对帧；两个构造实例；不合并、不外推 |
| 分层结构的死结已解开 | b2e（MAP-û1 硬 argmax）13/13 全败 ⇒ 被证伪的是"硬承诺"，不是 u1 信息量（826.27 b vs genie 826.37 b） | — |
| 预算是唯一硬约束 | A208 余量仅 **4.31 b**（< 1 行综合征 5 b） | 冻结口径 |

### 1.2 真正的脆弱点（按严重度排序）

1. **余量薄到不可认证 —— 这是当前最硬的风险，比"能不能纠"更硬。**
   对外可比要求 `f_eff = f_super + 4.7857·FER ≤ 1.3`；在 A208 基线下这要求
   `FER ≤ 0.1056%`。零失败臂的 95% 上界为 `3/N`（rule of three），故需要
   `N ≥ 3·4.7857/(1.3 − f_super)` = **2842**（A208）。
   而块数事实（`docs/decision-log.md:3078`：1M 2000 / 1p5M 2767 / 2M 3645 帧，
   合计 **8412 = 池总量，非每源**）：

   | 源 | 帧数 | n=1024 超帧数 | n=2048 超帧数 |
   |---|---|---|---|
   | 1M | 2000 | **500** | **250** |
   | 1p5M | 2767 | **691** | **345** |
   | 2M | 3645 | **911** | **455** |
   | 池合计 | 8412 | 2103 | 1051 |

   ⇒ **A208 基线上，即使三源合并（2103 < 2842），`f_eff ≤ 1.3` 也不可认证**；
   每源更不可能。这不是采样运气问题，是结构性不可达。
2. **`0/240` 只是 FER ≲ 1.25% 的界**（`3/240`）。旗舰数字需要更大的零失败样本，
   且样本量上界受上表封顶。
3. **f=1.2949 与 Müller LDPC 1.166 的 +0.129 缺口无法分解**（有限长 vs 结构化
   信道），文献给不出拆分（Zhou 曲线在 QBER 2% 二元、n≥2^16）。
4. **吞吐是未测量的弱轴。** b2f：240 块 / 672.6 s ⇒ **2.80 s/块**，
   即单线程 ≈ **1.83 kb/s**（5120 b/块）。对照 Müller 实测采集 **6.7 kbit/s**
   （注意：采集率，非 SKR、非 IR 吞吐）。IR 追不上采集 ⇒ "真实场景可用"目前
   是**空心的**，必须补测并优化。
5. **合成→真实的迁移未验证。** 合成帧由 2M 实测联合直方图生成的**无记忆符号级**
   模型驱动；真实帧是否有帧内/帧间记忆（漂移、相关）未检验。若存在，合成 FER
   系统性偏乐观。
6. **genie 退役句只能带作用域使用**（synthetic、两构造实例、不合并、不推广）。

### 1.3 结论（一句话）

**可解码性已解决；剩下的全部是"预算—认证—吞吐"三件事。** 因此宏观方向不是
继续找更强的解码器，而是：(i) 用**速率自适应**把 f 降到有认证余量的区间；
(ii) 用**真实数据 + 完整会计**把卖点做实；(iii) 用**吞吐工程**让"真实场景"成立。

## 2. 三项裁决（DECISION-1/2/3）

### DECISION-1 —— 验收门：双门并存，永不混用；旗舰数字必须"可认证"

- 保留内部门 (a) `FER ≤ 5%`（fails/240 ≤ 12）作为**路线继续/停止**门，不改。
- 对外一律**双数并列**：`f_super` 与 `f_eff = f_super + 4.7857·FER`，各自用
  **本臂自己的 m 基**（m=202 用 1.259759，m=208 用 1.294947；混基是被明令纠正过的缺陷）。
- **绝不允许**把 1.294947 / 1.259759 当 `f_eff` 报（它们仅在 FER=0 时相等）。
- 新增派生规则（本次裁决）：**任何进入对外材料的数字，其 FER 置信上界必须落在
  该臂的 f 余量之内**——即零失败样本量 `N ≥ ⌈3·4.7857/(1.3 − f_super)⌉`
  （rule of three，**向上取整**）。取值（复核后修正，原截断值作废）：

  | 臂 | f_super | 需要 N | 可得性 |
  |---|---|---|---|
  | n=1024 / A208 | 1.294947 | **2842** | ❌ 池合计仅 2103，每源 ≤911 |
  | n=1024 / f≈1.25 | ≈1.250 | **288** | ✅ 三源均 ≥500 |
  | n=2048 / m=416 | 1.2574 | **338** | ⚠️ 1M 仅 250 → 1M 源不可认证；1p5M/2M 可 |

- **作用域限定（重要）**：该规则**仅适用于零失败臂**。一旦出现 1 次失败，
  240 块的 Clopper–Pearson 上界 ≈1.94%，远超 f≈1.25 处的 1.045% 容限 ⇒
  任何 `FER > 0` 的臂在现有块数下**都不可认证** f_eff ≤ 1.3。
  ⇒ **P1 的目标必须写成"最终 FER = 0"，而非"期望泄漏"最优。** 这是硬约束，不是偏好。

### DECISION-2 —— 路线：候选 1 与候选 3 合并为一条主路线，候选 2 降级为构造子臂

理由（关键判断）：

- 候选 2（joint A2 n=2048）的立项动机是"分层拆出不可解码的稠密 L1 层
  （平均校验度 256–341 vs joint 19.7）"。但 **A3/软边际已经把 L1 码整个取消**
  （m1=0、D-u1=0、F208 0/240），该动机**已被溶解**；A2 不再是需要独立押注的路线。
  其 PEG@2048 构造工作与候选 3 共享，作为子臂并入，边际成本近零。
- 候选 1（条件救援）与候选 3（加长帧）**不是二选一，而是同一件事的两半**：
  条件救援 = 增量综合征 = **速率自适应**（Kasai 2010 / Müller blind /
  Chen 2025 IEEE 11440984 的直接同类）；加长帧 = 让自适应买到的余量变成可认证的余量。
- 文献对"有限长是 f 的主要分量"的支持（Zhou Table 4：1.190@2^16 → 1.056@2^27）
  使加长帧成为**有量化背书**的方向；但它改变科学输入 ⇒ DECIDE。
  ⚠️ 引用该曲线必须带来源标记：**arXiv-HTML 派生，PDF 未复核**
  （`LITERATURE_DIRECTION_MEMO_20260921.md` 出处优先级条款）——
  只能作方向性支持，**不得**作为数值结论的背书。

**主路线 = 速率自适应（增量综合征）NB-LDPC + 帧长缩放（n=2048 起），
joint A2 并入帧长研究的构造臂。**

### DECISION-3 —— 数据物理与安全口径：IR 不阻塞，安全结论阻塞

- 采纳用户输入 ①：**数据是 CW 时间-能量纠缠、高维到达时间（ToA）编码，d ≤ 1024；
  本项目的 IR 部分只消费 H(X|Y) 与实测 P(y|x)，与后续安全协议、是否为偏振/BBM92
  无关。** `SECURITY_MODEL.md` 中"polarization layer / BBM92-type"属于冻结 Polar
  管线的历史遗产，须加作用域更正（见 P0）。
- 因此 **PM/EB 未定案不再阻塞 IR 工作**。上游 `type2_2M_20260121_183657` 采集
  配置/记录本只在**撰写安全/协议章节**时才需要；取不到就按可操作描述写
  （CW SPDC 时间-能量纠缠、ToA 分箱、d=1024）并显式标注协议假设。
- **不做** composable 有限长安全性的主攻方向（那是姊妹篇/配套论文的事）。
  只保留一行桥接：Kanitschar & Huber 的 `leak_IR = leak_EC + log2(2/ε_EV)`
  ⇒ 我们的 64-bit tag ≡ `ε_EV ≈ 2⁻⁶³`。零成本，给安全审稿人一个挂钩。
- **IR 层对纠错效率问题的贡献维持下调**：IR 不改变量子侧安全性，只消费 H(X|Y)。

- **度量**：分段成功率、期望泄漏 `E[leak] = 5·200+64+40·(触发率)`、

- **预测（算术，非承诺，且证据不足）**：若基点 FER ≈ 10/240 且追加 8 行全部转化，

  ⇒ 可认证 N ≥ 288（三源 ≥500 块，够）。
  ⚠️ **"10/240" 缺乏直接证据**：可用锚点仅 b2f F202 6/240、b2g F202 4/240、

  m=200 的软边际 FER 必须**实测**，不得由外推预设。
- **机制依据（比原表述更强）**：b2f 的 6 个失败块与 b2g 的 4 个失败块、以及

- **动作**：(i) 实测**交互轮数/消息数**（对标 Müller 的 446 vs 3.14 messages，
