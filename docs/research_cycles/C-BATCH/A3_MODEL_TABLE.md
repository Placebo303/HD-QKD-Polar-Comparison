## 1. 模型模块

- 文件：`comparison_bench/src/comparison_bench/formal_ir/msd_a3_jitter_model.py`
  （新建，加法；高斯闭式复用 `msd_c2_fit` 的 `ternary_uncond`，未改动原文件）。
- 对任意 Δ 分布（零均值抖动形状 J + 残余偏移 μ），bin 误差通用式
  （`C2_DESIGN.md` §1.2 式(1)，符合窗截断式(4)）：
  `P(e=k) = (1/bw)∫₀^bw [F((k+1)bw−u−μ) − F(k·bw−u−μ)] du`，
  自写 Simpson 数值积分；输出 p₊、p₋、p、H(e)（全支撑 + rest 自成结局）与
  `h₂(p)+p·h₂(p₋)` 分解。
- 三族：`Gauss(σ)`、`GaussUniform(σ,ε)`（±200 ps 均匀底座）、
  `DoubleGauss(σ₁,σ₂,w)`。条件化（宽窗）对同一积分做 [−W,+W] 截断 + 归一。
- 自检（`--self-test`，合成零真实数据）：对称性 μ=0 → P₊₁=P₋₁；
  与 C-2 闭式三值 agree < 2e-4（两组 bw/μ/σ）；ε=w=0 时混合退化到高斯；
  纯高斯大 bw 极限 p<0.02。全部通过。
