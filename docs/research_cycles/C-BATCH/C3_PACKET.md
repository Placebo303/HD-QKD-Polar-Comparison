## 1. 信道输入（引用冻结）
- 采用 `C2_LOG.md` 发布的 estimator-C 规范值：每工作点族 (k, q, p_op 或 (σ,δ,ε_acc/重尾选择))。
- k=1 族必须含 C-0 校准后 p*（bw200 ≈ 0.057–0.069、bw400 ≈ 0.029–0.034，各源值）
  与模型预测的交叉残差（诊断列；调参用模型规范值，p* 只做交叉核对）。
- 若 C-2 对某层（宽窗 k≥2）判外推-only，则该层 C-3 格标记 `exploratory`，
  照跑照报（B≥300 同规则），不参与"已验证信道"主结论。
- 若 C-2 走 floor/重尾分支，采用分支规范（含 ε_acc），并在 log 首行声明分支名。

## 2. 工作点（新鲜层 ≤3 族，其余映射层）
- 新鲜层：k=1 的 (bw200-cal, bw400-cal) + 至多 1 个 C-2 核心一致的宽窗族。
- 映射层：A1/A2 的 G-5/Z-1/Z-3 历史行、A6 的 F-1/S-5/D-4 行，经 `net_of_cell`
  按 R16 重算后进入明细表，证据类型标 `mapped`（与新鲜 `fresh` 区分，R1§6 三类分开报告）。
- N 网格：{1024,2048,4096,8192,16384,32768,65536}；合成全跑，
  最优 N 选择受 `N_valid(WP)` 约束（由规划采集 C_total≈5M 对/点：
  floor(C_total/N)≥300；附无约束曲线备查）。

## 3. 冻结调参规则（同一规则，相对制，跨 p 可移植）
- 二进制臂（A1/A2）：`R = 1 − h2(p_op) − gap_bin(N) − margin_B`，
  `gap_bin = {1024:0.08, 2048:0.06, 4096:0.05, 8192:0.04, 16384:0.03, 32768:0.025, 65536:0.02}`，
  `margin_B = 0.01`（B≥300）。
- 高维臂（A3/A4）：`R = 1 − H_sym(p_op,k)/log2(q) − gap_nb(N) − margin_B`，
  `gap_nb = {1024:0.10, 2048:0.08, 4096:0.07, 8192:0.06, 16384:0.05, 32768:0.04, 65536:0.03}`。
- B 级 margin 阶梯 M ∈ {2.5, 3.0}：每 (WP,方法) 只在 N=16384 锚点二选一（按 Net_seg），
  选定后冻结用于该行其余 N（计算量封顶；Z-1 禁止的是跨 p 复用固定码，
  本包每 p_op 重算 R，不违规格）。
- 码构造：A1 高码率区 PEG 优先（RA 阈值崩先例见 FINAL_HANDOFF 诚实清单，
  若 RA 在某格失效记 `construction-fail` 保留证据，不得私自换规则）；
  A2 冻结集按 p_op 重算并记 hash；A3/A4 按包 §3.2/§3.3 构造器；
  `K=round(N·R)`，`K<1` 记 `infeasible`。
- A5：`layered_lite` 新鲜 wrap（若单格超时则标 `overtime-risk` 分片续跑）；
  A7：`unavailable` 列位（无 runner 即如实空缺，不得伪造）。

## 5. 记账与报告（R16，`net_of_cell` 为唯一口径函数）
- 主度量：Net_seg、Net_per_coin（分母 C_total 规划值；合成 B 下 w_tail 用规划 C_total 计，
  不用 B·N 倒推——口径写死）；f_full、FER 点估计、U 隔离、T_dec 中位/p95、
  相同译码时间 f（外推标 `extrap.`）、β 附带列 + 强制警示语。
- 主表：每 (WP,方法) 一行最优 N（行内 Net_seg 最大；并列差<1%取小 N 注 `tie→smallerN`）；
  附分 N 明细表；`mapped` 与 `fresh` 分表或分列，永不混排。
- "未定"：任一格 F≤9 或 S≤9 → `未定(F/S=n)`，不参与最优 N；全行未定 → `无有效最优（全未定）`；
  解封须补足 B 后 F≥10 且 S≥10。
