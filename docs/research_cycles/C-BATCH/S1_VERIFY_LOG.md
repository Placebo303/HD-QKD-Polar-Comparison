## 1. B2（`msd_b123_stats.py:212-259` `soft_gain`）——PASS（Bob 侧）

- 逐符号软输入唯一来源（L219）：
  `fine = ((pb[keep] − tmin) % bw)`，`sub = fine // (bw//8)`（L227）。
  `pb` = Bob 配对时刻（offset 只加在 A 侧，`_pair_nearest_unique:223`），
  `tmin` = 全段单一全局常量。**Δ（L≈`delta=pa−pb`，仅 B1 用）从未进入 `sub`**；
  Alice 时刻从未进入 `sub`。
- Alice 信息的三处出现（逐项定性）：
  1. `keep`（L217）：符合窗配对筛选——硬/软同一 kept 集，无差别选择（对称 pipeline）。
  2. `ee=(bb−aa)%d`（L224/235）：仅用于**打分**（经验熵估计必须用联合分布，
     与任何 H(A|B) 测量无异）；译码器侧不存在。
  3. `tmin`：全段 1 个标量，同时平移两网格；零逐符号 Alice 信息，
     且 S-2 前缀拟合的 μ 会整体吸收任何常数网格相位（见 §3）。
- 结论：B2 增益 G≈0.49–0.58 的输入是 Bob 侧的，**不作废，不重算**。
