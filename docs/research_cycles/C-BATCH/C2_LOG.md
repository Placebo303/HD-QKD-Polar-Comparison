## 2. 方法冻结点（实现与包/设计对应关系）

- 无条件式 (2)(3)：`A_func/ternary_uncond`；宽窗条件式 (4)：
  `cond_dist`（Simpson 自写）；支撑规则 (5)：`support_pred`
  （kdet 用 n·Pk≥5，kframe=d/2，khard=(W+|δ|+bw)/bw 上取整）。
- H 由落盘 top_errors 分数重算：`H_re=-Σq log2q-rest log2 rest`
  （rest=max(0,1-Σq) 自成结局）；非宽窗 rest=0，重算与落盘
  H_e 四位小数一致（逐源见 §3 表）。
- 权重：Var(p̂) 用 Wilson 区间半宽（10dB 小 n 自动降权，定性参与）；
  Var(Ĥ) 用多项式 plug-in 渐近方差；估计量 C 为逆方差加权。
- δ̂ 符号由前向模型自洽定（±|δ| 谁的主导侧符合观测 p− 就取谁），
  未 baked-in 任何 offset 符号假设。结果 δ̂0 ≈ −offset
  （T2-1M/0dB/4dB/10dB 为 +46..+49ps；T2-1.5M/2M 为 −50ps），
  与 C-0 方向翻转侧一致。
- floor (i) 形式：P0^f=P0^g(1−ε)，P±1^f=P±1^g(1−ε)+ε/2；
  ε̂ 由 6400 holdout 残差估计（可为负→截断 0，原文一并报告）。
- 层 χ²/dof 为描述性预测指数（dof=N 格）；正式优度检验为逐源 T2
  （{p200,p400,H200,H400}，dof=2，p=exp(−χ²/2)）。
- 未建模项（显式 floor）：同帧边界丢失（~1e-3 口径）、配对窗内
  nearest-unique 选择效应、TDC 量化相位。
