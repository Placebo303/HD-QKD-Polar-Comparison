## 3. 曲线形态（极小值附近 δ*∓5ps，证据充分性）
- 各格 p(δ*−5)、p(δ*)、p(δ*+5) 相差约 2e-05–0.008（如 T2-1M bw200：
  0.068009 / 0.060740 / 0.060767；10dB bw200：0.060430 / 0.056709 / 0.061109；
  最小平坦处如 4dB bw200 δ*/δ*+5 差约 1.7e-05），
  极小值在 5 ps 网格精度内平坦；10dB 的 −45（vs −50）差 0.0037，
  与其二项 SE（约 0.0024）同量级，不构成源间差异。
- 结论：δ* = −offset 符号侧 50 ps（即总位移约 ∓100 ps），6 源一致，网格精度 ±5 ps。

## 4. 机制读数（描述性，不外推）
- 标称点 p₋ ≈ 0.005（offset −50 源）或 ≈ 0.995（offset +50 源）：穿越几乎全朝一边，
  即符合峰被压在 200 ps bin 边界上。
- 最优点 p₋ ≈ 0.48–0.61：穿越均分两边，即峰被移到 bin 中央。方向翻转的符号与
  offset 符号严格对应（6/6），支持"bin 相位失准"是标称 p 的主导成分。
- 支撑：bw=400 最优点保持纯三值（sup=3）；bw=200 最优点出现第 4 值（±2），
  质量仅 1.3e-05–6.5e-05，可忽略，k=1 分组不变（C-2/C-3 输入时记 rest≈2–6e-05）。
