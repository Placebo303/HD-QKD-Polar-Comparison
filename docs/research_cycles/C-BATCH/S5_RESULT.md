# S-5a/S-5b合成调优结果（2026-10-09，`s5_tune.json` + `s5_gf5conf.json`）

> 上位：S-5 任务包（S-5a 软降码率 + S-5b 双修法取优）；S5B_PREEXECUTE（U 定义）。
> 方法：参数化 DoubleGauss（T2-1M 前缀律）+ 精细结构；随机 Bob 位；
> 选择口径：每对泄漏（确定性披露）+ 净密钥，FER≤0.05 门。
> 结论上限：合成选择；真实数由 S-5c 回答。

## 2. S-5b(i) 第三级：定量死亡

- w 平面（m3=128）：解码本身成立（6/6 探针），因标记位先验被 pin 住。
- w2 平面（a2^b2，借位 spill 使其天然 ~1.5% 稠密，不是 1e-5 稀疏）：
  m3'=320 + 诚实先验下失败率 ~1/6–1/3（6 块探针 5/6，200 块网格 U≈38%
  的主成分）。要降到可用需 m3'≈600+（0.15/对），则三级合计
  0.33+0.10+0.03+0.15 ≈ 0.61——与 S-4d 持平，**无增益**。
- 结论：(i) 放弃（不是"试过失败"，是定量证明无增益空间）。
  附带澄清：w2 稠密性的根源是正负 1 借位 spill（约 1.5%），不是宽事件；
  "微小第三级"的前提假设错了。

- e∈{−2..2} 作 GF(5) 符号，一次译码，±2 天然覆盖，exact 由 â=b−ê 直接保证；
  无交接、无补丁、无 U 来源（|e|≥3 质量 ~1e-9）。
- vs S-4d（0.61 泄漏，FER 0.05–0.23）：**泄漏 −20~28%，FER→0**。
  用户预言的"30–40%"在 level-A 口径成立（0.507→0.33）；端到端约 −20%
 （level-B 占比上升，属实记录）。
- N 选择（R16）：同泄漏率下 4096（配对 S-4d 硬链同块 + 时间减半）；
  8192 同效率但 2 倍时间 → **N\*=4096**。
