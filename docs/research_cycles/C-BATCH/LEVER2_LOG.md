## 1. 相对 void 包的唯一科学改动

void §1 的泄漏项 `leak_EC = f·H(A|B)_θ·n_k` → **S-4d 实测**：

```
lam_meas(arm) = (L_A + L_B) / (blocks × N)        # bits / pair（bw=200 校准链，N=4096）
leak_EC       = lam_meas × n_k                    # FK-A
FK-B 括号内的 f·H(A|B) 项同样换成 lam_meas
```

基线取 **hard/plain 接受格**（B0 = 今天真实可用的硬链全链）；`soft/plain` 接受格用于
L-soft 实测变体与对照。其余公式、ε 预算、网格、排序与 Q1–Q4 判读规则全部照 void §1/§2/§3。

## 6. Q1–Q4 判读（按 void §3 规则机械执行）

单元 = (源×T_cap×FK×V) = 5×2×2×3 = **60**；排名集合 8 个杠杆（L-f1.00 / L-soft / L-bw /
L-T10 / L-V0.99 / L-PE / L-eps / L-FER0.05；L-cal+soft 与 L-T∞ 按 void 排除）。

- **Q1（f 是否主导）：「f 非主导」**。L-f(→1.00) 在 **0/60** 单元排第 1；
  在 **60/60** 单元排第 3 或更后（实际名次 4–6：T=3 片 5(3)/6(27)，T=10 片 4(4)/5(26)）。
  阈值：≥2/3 排第 3 或更后 → 非主导（实测 100%）。
- **Q2（排序是否对 V 敏感）：未达阈值，不建议加 Franson 可见度测量条目**。
  rank-1 随 V 改变的组合 = **5/20**（全部是 T_cap=10 s × FK=A：V=0.90 时 L-V 第 1、
  V∈{0.95,0.98} 时 L-PE 第 1）；阈值 ≥1/3（6.67）→ 不触发。
  （附加事实：V 从 0.95→0.90 使 ℓ 下降 ~4.0%，0.95→0.98 上升 ~2.5%，
  即 V 的量级影响存在、但不改变多数单元的排名第一。）
- **Q3（B0 是否有密钥）：有**。zero_key=True 单元 **0/60**；T_cap=3 s 下 0/30。
  故不需要写「3 s 采集上杠杆是必要条件而非改进项」。
  （最小 raw ℓ = 4dB/3 s/FK-A/V=0.90/FER=0.10 的 775,302 bit，仍为正。）
- **Q4（分帧最优点是否随目标改变）：不一致 → 挑战方向 C 存活**。
  L-bw 下 ℓ 最大的 bw = **100**（60/60 单元，A5 模型行）；
  f·H(A|B)/H_A 最小的 bw = **400**（60/60 单元）→ 一致率 **0/60**。
  caveat：bw=100/400 的 H 来自 A5 模型（Z-3 的 bw=100/400 行带
  「UNMEASURED (extrapolation or wide-support regime)」状态，未入算式），
  且 H_A=log2 d 随 d 增长——**该判读依赖模型，并且正是 void 头注所说
  「bw/d 选点不能只在信息协调内评价」的同一现象**：目标不同 → 最优 bw 不同。

**f→S-4d-实测泄漏 的问题（按 void 原文口径）**：把 f 代理换成实测泄漏后，
「f 是不是最大杠杆」的答案没有翻转——仍是**非主导**，而且 f 的位置从
「相对重要」退到第 4–6 名（实测泄漏把 f 的自由度压到只剩 +0.8% 量级）。
