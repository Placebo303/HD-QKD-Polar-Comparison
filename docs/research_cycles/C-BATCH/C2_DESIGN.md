符号冻结：bw=bin宽(ps)；σ=抖动分布尺度(ps)；δ=残余时延(ps，按源独立)；
W=符合窗(~200ps)；d=SPAN/bw；e=(bb−aa) mod d；p=P(e≠0)；p−=P(e≡−1|e≠0)。
Z-2锚点：非宽窗三档 support恒为3；每源 (p200,p400,p6400)≈(0.23–0.26, 0.116–0.128, 0.007)；
p−按offset符号两极分化（−50ps源≈0.004–0.006主导+1；+50ps源≈0.99主导−1）；
宽窗两档 support为9(bw50)/5(bw100)；lag1≈0（i.i.d.二项方差可用）。

## 1. p(bw,σ,δ) 闭式/积分表达式

### 1.1 生成模型（假设A1–A4，验证中接受/拒绝）
- A1：真符合对差时 Δt = J + δ，J~f(·;σ)（基准高斯；备选Laplace/重尾）。
- A2：绝对时刻相对bin网格相位 u ~ Uniform[0,bw)。
- A3：sA=⌊(tA−t0)/bw⌋，sB=⌊(tA+Δ−t0)/bw⌋，同帧kept条件下 e=sB−sA。
- A4：配对保留 |Δ|≤W（一阶硬截断近似；W=200ps名义）。

### 1.2 无条件bin误差分布（任意抖动分布通用）
记 F 为 J 的CDF：
P(e=k | bw,σ,δ) = (1/bw) ∫₀^bw [F((k+1)bw−u−δ) − F(k·bw−u−δ)] du. …(1)
p = 1 − P₀；p− = P₋₁/(1−P₀)。

### 1.3 高斯闭式（基准模型）
A(a) = a·Φ(a/σ) − (a−bw)·Φ((a−bw)/σ) + σ[φ(a/σ) − φ((a−bw)/σ)] …(2)
Pk = [A((k+1)bw−δ) − A(k·bw−δ)] / bw …(3)
P₀=[A(bw−δ)−A(−δ)]/bw，p=1−P₀。δ→−δ下 P₊₁↔P₋₁对称，
解释 ±50ps offset源主导方向翻转。

### 1.4 非宽窗三值特例（bw=200/400/6400）
(P₋₁,P₀,P₊₁)由(3)给出；预测熵 Hpred 应与观测 H(e)对照；
预测 decomp=h2(p)+p·h2(p−)在非宽窗格应与落盘 decomp 重合。

### 1.5 宽窗条件化（bw=50/100，必须用条件式，不可套无条件式）
C(W;σ,δ)=P(|Δ|≤W)；P(e=k ∧ kept) = (1/bw)∫₀^bw ∫_{Ik(u)∩[−W,W]} φ((s−δ)/σ)/σ ds du …(4)
条件预测 Pk^cond=P(k∧kept)/C，p_cond=1−P₀^cond。

### 1.6 k-bin支撑扩展预测规则
khard=⌈(W+|δ̂|+bw)/bw⌉；kdet=max{k: n·Pk^cond ≥ 5}；kframe=⌊d/2⌋；
k_pred = min(khard, kdet, kframe)，support_pred = 2·k_pred+1 …(5)
标称：bw50→9–11；bw100→5；bw≥200→3。与Z-2（9/5/3）逐格对照，
另用 top_errors 尾质量数量级+单调性对照。

### 1.7 尾/底座扩展（bw=6400的p≈0.007，模型选择分支）
纯高斯大bw尾无法产生 p6400≈0.007。预注册floor项二选一：
(i) 偶发底座 p_total = 1−(1−p_gauss)(1−ε_acc)（ε_acc~0.005–0.008）；
(ii) 重尾抖动（Laplace/指数尾重算(1)）。
判别：ε_acc模型下p200/p400仍被高斯核拟合且仅6400需抬升→选(i)；
宽窗尾系统性高于高斯预测→倾向(ii)。必须报告"无floor纯高斯残差"作为拒绝证据之一。

## 2. σ估计（每源独立；≥两种估计量+一致性检验）

- **估计量A（两档联立反演）：** 解 p(200;σ,δ)=p̂200、p(400;σ,δ)=p̂400 得 (σ̂A,δ̂A)；
  符号由p−定；bw=6400留作holdout。
- **估计量B（H(e)拟合）：** min Σ[(Ĥ−Hpred)²/Var(Ĥ)]（200/400；6400参与时必须含floor模型）。
- **估计量C（联合仲裁）：** p+H加权最小二乘，用于最终报告值；A vs B 用于一致性检验。
- 一致性检验（α=0.05）：T1 σ一致性z（|zσ|>2判不一致）；T2 拟合优度χ²（χ²/dof≫1判误设）；
  T3 δ符号检验（与主导方向不一致直接拒绝）；T4 熵闭合t。任一失败→该源σ不跨源合并。

## 3. 验证方案（Z-2三十格 + C-0 δ曲线）

- 切分冻结：非宽窗200/400为拟合集，6400为floor-holdout，50/100宽窗为外推集；不拿宽窗点反调σ。
- 指标分层报告（不可混算掩盖宽窗退化）：非宽窗层（18格）RMSE/MAE/平均相对误差/最大残差/χ²/dof + 熵RMSE；
  宽窗层（12格）同样指标单独列表 + support对照 + 尾质量数量级对照（只报告不设通过门）；
  Holdout专项：6400残差与ε_acc估计。
- 通过参考（设计建议）：非宽窗 RMSE<0.005且平均相对误差<5%且χ²/dof<3 → "core-consistent"，
  否则换floor/重尾分支，不得放宽门限。
- C-0 δ–p曲线验证δ维度（σ冻结后的一维强检验）：预测 p_pred(δadd)=p(bw;σ̂C, δ̂0+δadd) 无新自由参数；
  检验①最优点 Δδ*应<min(10ps,0.1·bw)；②曲率 κ_obs/κ_pred参考带0.7–1.3 + 曲线RMSE；
  ③方向单调性。宽窗扫描须用条件式(4)预测。

## 4. 适用边界与R1功效说明

- 欠采样格（bw50/100）禁用σ/δ估计，仅外推验证；support结论止于机制一致/数量级。
- 宽窗须切换条件式(4)；宽窗RMSE预期比非宽窗大≥3×，分层列出即合规。
- 10dB小样本（n=30907）：σ̂用Wilson精确区间、权重最低、只参与六源定性检查。
- d=32 fold与帧边界：公式保留fold项；同帧丢弃~10⁻³口径须与Z-2 keep逻辑一致；跨源禁止合并σ。
- R1功效：本验证主张是拟合一致性（估计+拟合优度），不是解码器FER/SKR提升，解码MDE不适用；
  等效可检失配MDM：T2-1M bw200约0.0012(0.5%相对)、bw400约0.0009、bw6400约0.0002；
  10dB bw200约0.0048。非宽窗5%相对偏离在大n源上高度可检；向FER/SKR的推广仍需另立DECIDE。
