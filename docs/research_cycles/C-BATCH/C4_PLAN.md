## 2. 每点事件数与时长

- 标准点：**约 500 万对符合**（= 300 块 × N=16384，B≥300 门；另前缀约 1 万对只做参数估计）。
- 最终点（W1b、W2b 建议）：**约 1700 万对符合**（最优 N 若落在 16384 时 B≥1000；
  若只到 B≥300 标准，维持 500 万即可，C-5 Pre-EXECUTE 时按 C-3 最优 N 落定）。
- 时长换算（按已测对率外推，**请按当前装置实测对率 R_pair 等比缩放**）：
  时长 ≈ 目标对数 / R_pair；前缀估计段可忽略不计。
  参考：89k 对/s（0dB 档）→ 500 万约 56 s，1700 万约 3.2 min；
  38k 对/s（4dB 档）→ 约 2.2 min / 7.5 min；
  10k 对/s（10dB 档）→ 约 8 min / 28 min。
- 若单段 10 s 不够：采多段短采集并按段报告（段号、起止、对数），C-5 按段切分、
  前缀估计与测试块按时间切分（前缀只用段首约 1 万对）。

## 3. 校准前置（C-0 结论的操作化，必做）
1. 时钟相位：将符合峰调到 bin 中央（判据：p₋ 回到 ~0.5，而非 ≈0/1 的一边倒；
   C-0 标称点 p₋≈0.005/0.995 即峰压边界的特征）。
2. 配对 offset 与分 bin 相位都要校（C-0 对照：±100ps 配对位移本身即致 p 恶化）。
3. 先采 1 段试采，用 C-0 同口径（δ 扫描步长 ≤5ps，零解码）确认本装置的 δ* 后再批量采；
   C-0 的 ∓50ps 是旧装置值，**不得直接套用**。
4. 每段记录：原始 ttbin 完整事件、装置衰减档、采集时长、bin 宽与符合窗设置、
   对准 offset；新采数据在使用前一律视为干净 OOS（前缀估计除外）。

## 6. Run sheet 与段级 manifest 字段（A7 新增，必填）

每段采集的 run sheet（一行一段）与落盘 manifest 必须含以下字段，缺失视为不合格段：

| 字段 | 说明 |
|---|---|
| `source_type` | 光源类型（Type-0 / Type-II / 其他，按装置记录写） |
| `split_filter` | 分路方式 / 滤波配置（nofilter / 单滤波 / 双滤波 + 滤波片参数） |
| `singles_A_per_s`、`singles_B_per_s` | 两路 singles（Hz，采前读数 + 采后读数） |
| `coin_rate_per_s` | 符合率（Hz，实测） |
| `voa_setting_db`、`voa_arm` | VOA 设置（dB）及所在路（A 路 / B 路 / 双路） |
| `pump` | 泵浦条件（功率/波长，按装置记录写） |
| `duration_s` | 采集时长（s） |
| `pre_calib_delta_ps` | 采前时延校准值（ps，用 C-0 同口径确认的本装置 δ*） |
| `file_path` | 原始文件路径（含变体 base/`.1`） |
| `bw_window_plan` | 计划分帧（bw、符合窗、span displacement 由后处理定） |

## 7. A7 采集纪律（新增）

- **矩阵**：光源 × singles × VOA（§1 六点即此矩阵的实例化）；增删点须同步更新 §5。
- **每点双段异时**：每个矩阵点在不同时间各采 2 段（中间间隔开装置漂移），
  两段分开报告、不合并；单段结论须经另一段复现才成立。
- **T0 复现检查**：首段采完先做 C-0 同口径零解码快照（δ 粗扫 + p/p₋），
  与历史同类点对得上才继续采第二段。
- **偶然符合背景段**：每光源至少采 1 段失配延迟（如 +10 ns 偏移）的背景段，
  用于偶然符合率标定（CAR 分母的实测锚点，不只靠公式估计）。
- **ps 级原始时间戳必须保留**：落盘最小单元为 ps 分辨率原始事件流
  （ttbin base + `.1` 变体齐全）；任何只存分 bin 结果、不存原始戳的段视为不合格。
- **长段分子段漂移检查**：单段 ≥ 60 s 的，按时间 3 等分子段估计 μ（B1 同口径），
  漂移 > 10 ps 的段标记并分开报告（提示重采或拆段使用）。
