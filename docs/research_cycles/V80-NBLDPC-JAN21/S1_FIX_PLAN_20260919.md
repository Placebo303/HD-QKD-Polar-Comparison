## F1 — PRIMARY layer-local rate grid (blocking)

- Root cause: PRIMARY runs the GF(32) **L2 layer** (sampler `P(U2|B,U1)`,
  width 5) at full-symbol budget grid m∈[24,31] → rate = 1−m/256 ∈
  0.879–0.906. L2 feasibility requires
  **rate ≤ 1 − H_L2/5 = 1 − 0.80690067/5 = 0.83862**
  (leak ≥ H_L2 per symbol). Every executed grid point is above capacity →
  0/420 DE convergence is theory-consistent.
- Correct mapping: **m₂ = ceil(f·H_L2·n/5) = ceil(41.31·f)** (n=256):
  f=1.3 ⇒ m₂≈54; sweep f≈1.05–1.45 ⇒ **m₂≈44–60**.
  Precedent: V26 F03-GF32+GF32 @ f=1.3 "30/30 narrow pass" (decision-log 4436).
- Delta direction (for coder packet, not executed here):
  PRIMARY arm must use its own layer-local grid (m₂ ≈ 44–60 or equivalent
  f-parameterized grid), `rate = 1 − m₂/n` evaluated against the L2 width-5
  budget; full-symbol m 24–31 must not be reused for L2.
- SECONDARY (width 10, direct-q1024) grid m 24–31 is feasible as a budget, but
  its gate/reporting needs the F2 fix below; it reruns under the same fresh grant.
- PRIMARY's consumed 420 slots are **not recyclable** — arm must rerun.

## F2 — gate semantics (blocking)

- Defect: `evaluate_gate` (runner 866–876) filters arm/phase=confirm/status=ok/
  `f_row` present, takes `f_ens = max(f_row)`, passes iff ≤ 1.15. It **never
  consults `converged`**; `f_row = (1−rate)·width/h_meas` (line 538) is pure
  config arithmetic.
- Consequences on record: PRIMARY `pass (0.7506)` from 0 converged rows, with
  f<1 violating the Slepian–Wolf bound (itself the F1 fingerprint); SECONDARY
  max over confirm ≈ **1.454 (m=31) > 1.15** ⇒ as-coded SECONDARY can never pass.
- Delta direction:
  - Gate must screen `converged` (e.g. **∃ converged row with f_row ≤ 1.15**);
    empty-converged-set ⇒ explicit non-pass, never max-of-unconverged.
  - Orientation pin: **f < 1 refuses/pins as SW-bound violation** (informative
    failure, not a pass).
  - Concrete pass bars: SECONDARY needs an **m=24 config to converge**
    (f_row≈1.126, the only grid point ≤1.15); PRIMARY-fixed needs **m₂ ≤ 47**
    (1.15·H_L2·256/5 ≈ 47.5).
  - `verify.ok` (hash + gate-recompute consistency) **≠ gate adjudication** —
    record and report must label it as such.
  - **Flip cross-unit comparison forbidden**: PRIMARY f (layer units) vs
    SECONDARY f (full-symbol units) must not be compared; flip computes only
    within a shared unit basis or is withheld with reason.
