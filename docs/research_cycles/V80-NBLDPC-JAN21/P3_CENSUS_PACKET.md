## 5. Frozen estimator definition for H_full (ONE definition; others reconciled)

- **Primary (frozen)**: `H_full ≡ H_L1 + H_L2` under factorization **F03** (`u1 = A>>5`, `u2 = A&31`, each GF(32)), i.e. `nonbinary_v26_channel.py::ChannelAdapter._build_entropy` verbatim: `P(a|b) = N_ab[a,b] / N_ab[:,b]` (plug-in, no backoff, zero cells dropped rather than floored), `H_L1 = Σ_b p_b·H(P(·|b))` over `u1`, `H_L2 = Σ_b p_b Σ_u1 p(u1|b)·H(P(·|b,u1))` over `u2`, `p_b = N_ab[:,b]/ΣN_ab`. Units: **bits per GF(32) symbol** (5 bits/symbol). This is the estimator that produced the frozen anchors, so the census stays inside one convention.

## 6. Bias / uncertainty rule (anti-sparse-artifact)

Plug-in entropy is biased **LOW**, and the bias grows as the histogram sparsifies — exactly the regime where a low `H_full` looks attractive. A doubled stream (both-member concatenation, FORBIDDEN in §2) would silently corrupt every item below — counts, support, MM correction, held-out gap, and CI alike — so the §2 prohibition gates this entire section. Therefore, **per dataset, MANDATORY**:

1. **Raw coincidence counts `N`** (not fractions), the full `N_ab` occupancy map, **support size** (number of occupied `(a,b)` cells), and **occupancy** = support/(1024×1024). Reported, never suppressed.
2. **Miller–Madow correction** `Ĥ_MM = Ĥ_plug + (K − 1)/(2N·ln2)` with `K` = number of occupied joint cells (frozen formula, stated here so it cannot be chosen post hoc). Reported next to, never instead of, the plug-in value.
3. **Held-out generalization gap** under the V49 convention (§7.3): `Δ = NLL_HOLD − H_TRAIN`. This is the same functional that exposed the anchor's own +0.0204 gap.
4. **Bootstrap CI** (frame-level resampling, ≥ 200 resamples, frozen seed recorded) — **required for every dataset whose `H_full` is below the anchor `0.83256272`**, i.e. for every dataset that would look like a "better channel". A dataset may not be promoted to a design-point candidate on a point estimate alone.
5. **Hard rule**: any `H_full` used for a design-point decision must carry an uncertainty statement (CI half-width + bias diagnostic). A sparse-histogram artifact must not be allowed to look like a better channel. If support/occupancy is so low that the CI half-width exceeds a frozen threshold (proposed `0.02 b/symbol`, matching `nonbinary_v26_gate.py::ENTROPY_TOL_BITS = 0.01` granularity precedent — **[TO BE CONFIRMED at the authorization gate]**), the dataset is reported as `INSUFFICIENT-SUPPORT` and excluded from ranking.
