## 1. 假设（单一，可证伪）

在**同一份真实数据**上，G6/G7 高维管线的净负不是数据本身造成的，而是解码器
先验把每符号条件熵当成 `H_eff ≈ 4.343 bits/symbol`（近均匀）来付泄漏；
真条件熵锚点为 `H(A|B)/H_full ≈ 0.55–0.80 bits/symbol`（V25 / V19 实测）。
若能用 Bob 全符号条件化的经验先验把 `H_eff` 压到 **≤ 1.023 bits/symbol**，
则 n=128 / Â=0.6 / tag 64 下净收益转正（`N = 320 − 8m`，`m ≤ 39`）。

## 2. 互斥解释（由同一次测量区分）

- (a) **先验盲**：真条件熵仍 ≈0.55，只是先验没用 Bob 侧信息 → 修先验即可；
- (b) **表示脏**：G6/G7 块（R2DIAG true_weight 119–128/128）确实比二元位面
  （V17 逐位面 BER ≈3.8%）脏，真条件熵本身接近 4.3 → 必须先对齐/条件化，
  再谈纠错，且当前分帧下的净正目标应判负。

## 3. 测量设计（只读，零解码器调用）

在**已冻结的 USED/CAL pool**（不新选块、不挑帧、不重抽取）上计算三项每符号
条件熵，全部只读、不写证据根、不调用解码器：

- `H_A`：当前 Model-F 先验的每符号熵（预期复现 ≈4.343，作为口径自检）；
- `H_B`：Bob **全符号**条件化的经验模型 `P(U_plane | B_full, session, delay)`
  的每符号熵（V25 delta 模型 / V19 逐位面条件 LLR 口径）；
- `H_C`：在 `H_B` 基础上再叠加对齐/延迟条件化后的每符号熵。

输出：三个数值 + 样本量 + 口径说明（每符号 vs 每块）。预算：分钟级，零
decoder calls，零 graph 构造。

## 4. 判据（冻结，二元决策）

- `H_B ≤ 1.023` → 解释 (a) 成立：授权进入"条件先验 → DE/有限码"下一臂
  （目标 m/n ≈ 0.11–0.16，m ≈ 15–25，净 ≈ +120…+200 bits/帧）。
- `H_B > 1.875` → 解释 (b) 成立：当前分帧下净正**信息论不可达**，路由应转向
  "先对齐/条件化再纠错"，并按二元管线的表示口径重建分帧；不得继续调码。
- 两者之间（`1.023 < H_B ≤ 1.875`）→ 净正在 n=128 不可达但增大 n 有可能
  （通式 `N = n[3 − 1.6H] − 102.4`），单列决策点，不自动推进。
