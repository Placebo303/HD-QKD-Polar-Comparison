## Receiver/sender interface milestone (implementation only)

The next module preserves full-Bob conditional information through actual decoded-prefix propagation and explicit syndrome disclosure, preparing measurement of real-data efficiency. It does not measure a gain. The implementation-only boundary above remains: all executed tests inject fake decoders; no production decoder constructor, decode, experiment, graph/rate selection or dataset read occurs.

Luna owns only new `comparison_bench/src/comparison_bench/formal_ir/msd_syndrome.py` and `comparison_bench/tests/test_msd_syndrome.py`. Main owns these requirements, change/log and acceptance; other agents are present and their edits must be preserved.

- M6: sender function takes natural Alice symbols, the model's explicit encoding/order and one caller-supplied binary parity matrix per stage. Return only public syndromes s=(H@encoded_A)%2 and actual transmitted row count in bits/block; dependent rows are still transmitted and counted, including zero rows. This is transmitted syndrome disclosure, not an independent-information rank claim. Never discount rank or include a tag implicitly. Validate Alice as a one-dimensional integer vector in [0,Q) of length N, matching stage count, binary matrices and common block width. Use sparse CSR matrices for the interface, without generating a graph or selecting a rate.
- M7: receiver takes model, natural Bob symbols, matrices and public syndromes, plus a mandatory explicit decoder factory. It never takes Alice truth. At each stage query the prior using the previously recovered stage bits, form MAP base=(p_one>0.5), p_error=min(p_one,1-p_one) and delta = public syndrome XOR H*base modulo two. This interface consumes error probabilities, so it has no unused LLR/floor parameter. Call factory with keyword `parity_check_matrix` and `error_channel` (the per-variable p_error vector); call its returned object's `decode(delta)`; recover bits = base XOR estimated error. Check (H@recovered)%2==public syndrome; a failed check stops before subsequent stages. Binary/shape-invalid decoder output raises a clear error. Return recovered stage bits, reconstructed natural symbols only when every stage passes, attempted-stage syndrome flags and unsupported counts, and transmitted row count. Syndrome satisfaction is not verified success or FER. No acceptance/tag implementation or truth comparison is in this receiver.
- M8: separate explicitly selected `make_bp_decoder` factory lazily imports ldpc and constructs BpDecoder with sparse PCM, per-variable probabilities, `input_vector_type='syndrome'`, deterministic parallel schedule, one OMP thread and an explicit positive max_iter argument (no default budget). The caller must bind that budget before passing the factory to the receiver, e.g. functools.partial(make_bp_decoder,max_iter=...). It is never the receiver's default; no production ldpc.BpDecoder constructors are invoked in tests, while fake constructors are allowed. Do not claim backend equivalence or performance before a future gated run. Encoding round-trip supports natural/Gray and both complete orders without copying sibling code.
- M9: fixed fake-decoder fixtures cover nonzero error-delta correction, all four encoding/order combinations (NATURAL/GRAY times LSB/MSB), per-variable soft vector forwarding, propagation of actual recovered rather than oracle prefixes (including a syndrome-satisfying wrong prefix), early syndrome failure, dependent-row/zero-row leakage counting, invalid Alice/stage/matrix/syndrome/output shapes and nonbinary/out-of-domain values. No RNG, saved input access or empirical outcomes. Tests use .venv, timeout 120, pytest -p no:cacheprovider -o addopts= and fresh workspace/msd_syndrome/<uuid>; retain exact failures.
